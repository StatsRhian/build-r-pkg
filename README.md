# 📦 If You Can Write a Function, You Can Build an R Package

Build your first R package — without the fear.

This repository contains the materials for the “You can build an R package” workshop.

👉 Full workshop details, slides, and resources are available on the project website:
[statsrhian.github.io/build-r-pkg](https://statsrhian.github.io/build-r-pkg/)

You’ll learn:

- What goes inside an R package

- How to add and document functions

- How to share your package with others

If you can write a basic R function, you _can_ build a package. 🚀
